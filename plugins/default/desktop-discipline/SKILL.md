# 共享桌面与图层纪律（Desktop Discipline）

**前提：这台机器的桌面是用户正在用的工作台，不是 agent 的画布。** 任何用户可见的窗口、前台焦点、鼠标键盘输入，都是对用户工作面的侵入。用户为本纪律给过两句原话：

> 「你不能把图放到顶层覆盖」
> 「不然每次操作都很麻烦我要用电脑都很麻烦」

事故原型（v2 产品片取素材那一轮）：为读一张 PNG 里的小字，agent 用「无边框置顶看图窗口 + `computer_screenshot`」逐面板回读。窗口是置顶的，盖在用户正在用的应用上；另一个 teammate 随后要截图时又抓到别人的看图窗口，两次互相污染，复读结果作废。**读像素本来不需要任何窗口。**

---

## 一、红线（默认禁止，不问不做）

1. **禁止置顶/覆盖**：不创建、不保留 any 置顶（always-on-top / topmost）、全屏、最大化窗口；任何窗口都不得压在用户正在用的应用之上。
2. **禁止改用户的窗口状态**：不 `move` / `resize` / `maximize` / `minimize` / `close` 用户的窗口；不 `computer_focus` 别人的窗口抢前台；不用 `win+up`、`alt+f4`、`alt+tab` 这类组合键作用于他人窗口。
3. **禁止未经请求的合成输入**：`computer_click` / `type` / `keys` / `drag` / `scroll` 只在**用户明确要求操作界面**时使用；不用输入去"试探"或"矫正"界面。
4. **禁止跨轮留窗**：本轮开的任何窗口必须**在同一轮内关闭**；不留下 viewer / 预览 / 探针进程。不 `Start-Process` 打开图片、不动系统看图器。
5. **禁止抢跑**：团队并行时，桌面只有一个；不确定别人是否在用，就一律走无窗口路径。

## 二、读像素 / 读文字的能力调用顺序（必须按序降到下一档）

1. **结构化数据优先**：能从源码、JSON、日志、记录里读到的，就不要"看图"（`read_file` / `grep_search` / `bash_read`）。
2. **文字用 OCR**：`Windows.Media.Ocr`（PowerShell，`zh-Hans-CN` / `en`）。先全图 1×，再局部放大 2×/4× 复读；小字抗锯齿放大后会崩，那就换区域、换阈值，把**原始读数**和"读不出"一起记下来。
3. **结构用算术**：PIL / numpy 做裁切、缩放、行/列暗带剖面、直方图、`mean|diff|`、相关系数。**几何量测（行带 y 边界、裁切框）一律用量测值，不许目测。**
4. **视频用解码**：ffmpeg（`imageio-ffmpeg` 带的那个）/ PyAV 抽帧到 `_tmp/`，再走 2、3 两档。抽帧、探针、放大图只写 `_tmp/`。
5. **真的只能开窗时**：必须**先拿到用户当场同意**；窗口不置顶、不最大化、放最小尺寸在空白处，**当轮关闭**，并在回执里写明"为什么无窗口路径不够用"。
6. **把 `computer_*` 当破坏性能力**：用之前先自问"有没有无窗口替代"；用了就在回执里写清用了哪一步、为什么。

> 对照：同一张 PNG 的标签读数，OCR 路径给出的结果与"置顶看图窗口"路径一致，但零侵入、可复跑、可贴命令当凭证 —— 后者反过来污染了另一个 teammate 的截图证据。

## 三、leader 派活纪律

- 每个 teammate 的 goal 里必须带一句本纪律（例如「桌面纪律：不许开置顶窗口盖住用户桌面，读像素走 OCR/PIL 无窗口路径」）。
- 验收时检查：有没有多余窗口、有没有前台抢占、有没有把别人的截图/画面拍进自己的证据里。

## 四、自检清单（动手前过一遍）

- [ ] 我这个操作会不会在用户屏幕上多出/变动一个窗口？
- [ ] 我要的这个信息，能不能用 read_file / grep / OCR / numpy / ffmpeg 拿到？
- [ ] 如果必须开窗：用户同意了吗？不置顶吗？当轮关掉了吗？
- [ ] 我的回执里，证据是不是"命令 + 读数"（可复跑），而不是"我看了一眼"？
