# Code of Conduct

## Our standard

Participants are expected to communicate with respect, focus criticism on technical work, provide reproducible evidence where possible, and make room for people with different backgrounds and experience levels.

Unacceptable behavior includes harassment, threats, discriminatory language, deliberate disclosure of private information, sustained personal attacks, spam, and publishing another person's credentials or private project data.

## Scope

This standard applies in repository Issues, Pull Requests, Discussions, review comments and other project spaces, as well as when someone is representing the project publicly.

## Enforcement

Project maintainers may edit or remove comments, close interactions, reject contributions, temporarily restrict participation or permanently ban participants when behavior violates this policy. Enforcement decisions should be proportional, documented where appropriate and focused on protecting project participants.

For a sensitive conduct report, contact the maintainer through a private GitHub channel rather than posting personal information publicly. Reports will be reviewed as confidentially as the platform and investigation permit.

This policy is adapted from the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
