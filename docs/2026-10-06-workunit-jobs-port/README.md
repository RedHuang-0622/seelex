# workunit 端口化：三步交接包（入口）

**一句话**：让"一件活"的每件事**只有一个出处**——谁在跑、干到哪了、现场在哪、怎么接着干、什么时候拆，
每个都只留一份实现，能单独换、能单独假（不需要真 git、真进程）。

| 步骤 | 一句话 | 状态 | 看哪份文件 |
|---|---|---|---|
| ① 只定接口 | 把"作业面"从"只有 Reclaim"扩成完整形状；两张表都先不动 | **已落地 + 复核 PASS**（`a6f8f2b`） | `step-1-delivery.md`（开工前的提示词 = `handoff-prompt.md`） |
| ② 并判据/读法/容器 | 把"记录→进度"折算、阶段编解码、恢复说明各并成一处；**不合表** | 提示词就绪，可开工 | `step-2-handoff-prompt.md` |
| ③ 现场/进程树收口 | 删现场两个函数合成一个幂等实现、脏判定三份收一份、进程树装配两份收一份；两个缺陷红灯先行 | 提示词就绪，可开工 | `step-3-handoff-prompt.md` |
| ④（候选，未定稿） | 恢复名单登记收进 `workunit`；teammate 恢复续跑（要过 leader 闸门） | 需你裁决 | `../arch/workunit-duplication-inventory.md` §二 #1 / #7 |
| ✗ 已关闭 | 两张作业表合一（迁到 Seele `jobs.Manager`） | 2026-10-01 裁决否决，**不再开工** | `../arch/teamwork-leader-worker-architecture.md` §12.4 |

每份提示词都是同一个三块结构：**前置**（必须知道的事实 + 纪律 + 已知例外）→ **先读哪些文件**（唯一口径，按序）
→ **做到什么程度算完成**（判据 + 红线 + 交付格式）。每份都自带基线提交号，新会话不用问从哪里开始。

**顺序不是随便定的**：① 定形状 → ② 让"同一件事判两遍"的地方真正只剩一份 → ③ 再动现场/进程树的动作重复。
② 只在 `session/subagent_sessions.go`、`workunit_team_records.go` 上动手；③ 主要在 `worktree_manager.go`、
`tools/async_run.go`、`tools/router.go`——两波基本不打架，③ 甚至可以先做不交叠的那几条。

**每次交付的门槛（AGENTS.md §8）**：列删除清单（旧那份去哪了）、给"只剩一份实现"的 grep 读数、
给命令原始读数；**只加不改的交付一律退回**。
